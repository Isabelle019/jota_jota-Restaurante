# Jota Jota — Cardápio Digital

Site estático responsivo, pronto para GitHub Pages.

## Estrutura
- `index.html` — página inicial e navegação entre as nove seções do cardápio.
- `css/style.css` — identidade visual preta, vermelha e amarela.
- `js/script.js` — navegação entre páginas.
- `assets/imagens/` — fotografias em WebP.

## Publicação
Envie todo o conteúdo desta pasta para a raiz do repositório. Em **Settings → Pages**, selecione **Deploy from a branch**, branch **main**, pasta **/(root)**.

Todos os caminhos são relativos e compatíveis com GitHub Pages em um repositório de projeto.
